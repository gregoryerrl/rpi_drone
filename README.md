# Raspberry Pi drone projects

Each aircraft has its own directory for hardware notes, experiments and setup instructions.

- [Haras Amor](haras-amor/README.md) pairs a Raspberry Pi 5 with a MicoAir743v2 flight controller. Its experiments include an RC channel monitor and a camera-stand test using the same radio.

For Raspberry Pi provisioning, SSH and the fallback Wi-Fi hotspot, see the [Pi setup template](https://github.com/gregoryerrl/rpi_dev).
